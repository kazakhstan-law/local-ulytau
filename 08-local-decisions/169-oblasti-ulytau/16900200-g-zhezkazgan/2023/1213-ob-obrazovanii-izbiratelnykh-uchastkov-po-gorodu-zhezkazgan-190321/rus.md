# Об образовании избирательных участков по городу Жезказган

В соответствии со статьей 23 Конституционного закона Республики Казахстан «О выборах в Республике Казахстан», аким города Жезказган РЕШИЛ:

<a id="p1"></a>

1. Образовать избирательные участки по городу Жезказган согласно приложению к настоящему решению.

<a id="p2"></a>

2. Признать утратившим силу решение акима города Жезказган «Об образовании избирательных участков» от 9 января 2019 года №01 (зарегистрировано в Реестре государственной регистрации нормативных правовых актов за №5138).

<a id="p3"></a>

3. Контроль за исполнением настоящего решения возложить на руководителя аппарата акима города Жезказган.

<a id="p4"></a>

4. Настоящее решение вводится в действие со дня его первого официального опубликования.
